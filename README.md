# Predictive Modeling in Volleyball

This repository contains the code and sample outputs for my Master's thesis on predictive analytics in volleyball using XGBoost. The written thesis document, which provides detailed explanations of the model and all generated graphs, is included here alongside all necessary data.

## 1. Repository Structure
- **Data/**: contains the datasets used for the project. 
  - `A2f_202526/`: contains the data for the 220 games used to train the model.
  - `experiments/`: contains the raw data of 5 extra games used as case studies.
- **src/**: contains the 5 Python scripts, the pre-trained XGBoost model (`volleyball_xg_model.pkl`) and the list of columns used in the training (`training_columns.pkl`).
- **output_examples/**: contains the graphs and analysis files generated by the code for the 5 case study games.

## 2. Requirements & Installation
You will need Python installed. Several of the imported modules (like `os`, `glob`, and `warnings`) are built into Python, but you must install the external libraries. 

You can install all required dependencies by running this command in your terminal:
```bash
pip install numpy pandas datavolley joblib xgboost scikit-learn matplotlib seaborn adjustText
```

## 3. How to Run the Code
There are two ways to use this repository:

### Option A: Analyze a Game (Using Pre-trained Model)
If you only want to analyze a game, you do not need to retrain the model. You can use the provided `volleyball_xg_model.pkl` and `training_columns.pkl`.

**1. Configure the Scripts**
*   **Testing an existing game:** to analyze one of the games in the `experiments` folder, simply change the `folder` variable in all three analysis scripts to match the name of the game you want to test.
*   **Testing a completely new game:** change the `folder` variable in all three scripts (this folder name acts as the `.dvw` file name). Additionally, open `src/3_one_hot_one.py` and change the `file_path` variable to point to the location of your new `.dvw` file.
*   **Select a team:** in `src/5_team_analysis.py`, you can modify the `focus_team` variable to specify which team you want to analyze.

**2. Run the Analysis**

Execute the scripts in this order:
- `python3 src/3_one_hot_one.py`
- `python3 src/4_xg_new_match.py`
- `python3 src/5_team_analysis.py`

### Option B: Retrain the Model from Scratch
If you want to recreate the model using the 220 training games in the `A2f_202526` folder, run the training scripts in this order:
1. `python3 src/1_final_dataset_onehot.py`
2. `python3 src/2_XGBoost.py`
*(This will generate a new version of the `volleyball_xg_model.pkl` file).*
