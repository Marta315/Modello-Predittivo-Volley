# Predictive Modeling in Volleyball

This repository contains the code, models, and sample outputs for my Master's thesis on predictive analytics in volleyball using XGBoost. All necessary data is included directly in the repository.

## 1. Repository Structure
- **Data/**: Contains the datasets used for the project. 
  - `A2f_202526/`: Contains the data for the 220 games used to train the model.
  - `experiments/`: Contains the raw data of 5 extra games used as case studies.
- **src/**: Contains the 5 Python scripts, the pre-trained XGBoost model (`volleyball_xg_model.pkl`) and the list of columns used in the training (`training_columns.pkl`).
- **output_examples/**: Contains the graphs and analysis files generated by the code for the 5 case study games.

## 3. How to Run the Code
There are two ways to use this repository:
### Option A: Analyze a New Game (Using Pre-trained Model)
If you only want to analyze a game, you do not need to retrain the model. You can use the provided `volleyball_xg_model.pkl` and `training_columns.pkl`.
1. Insert the data for the game you want to study into the appropriate script.
2. Run the analysis scripts in this order:
   - `python3 src/3_one_hot_one.py`
   - `python3 src/4_xg_new_match.py`
   - `python3 src/5_team_analysis.py`

### Option B: Retrain the Model from Scratch
If you want to recreate the model using the 220 training games in the `A2f_202526` folder, run the training scripts in this order:
1. `python3 src/1_final_dataset_onehot.py`
2. `python3 src/2_XGBoost.py`
*(This will generate a new version of the `volleyball_xg_model.pkl` and `training_columns.pkl` files).*
